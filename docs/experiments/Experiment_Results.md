# 实验结果数据

本文维护各实验的身份、原始结果、BD-rate 和数据完整性。结果解释、机制假设及后续建议单独放在 [实验分析](Experiment_Analysis.md)。数值文档上传 Git；工作簿、CSV 和本地导入记录保留在 `experiments/`。

## 登记与填写约定

- 每个实验固定编号，在 `experiments/experiment_<三位编号>_<名称>/` 保存表格数据；当前 4×4 GTT 为实验 1。
- 保留收到的 CSV 和 `results.xlsm` 原件，复制模板生成实验目录下的 `results.xlsm`。按序列、QP、配置匹配 Test 行，不按 CSV 行号直接粘贴；`.ecm.` 和 `.jvet10.` 是布局标签，不据此认定软件身份。
- 新实验副本清空旧 Test 测量值，缺失点留空；Reference、VBA、公式和行布局保留，旧公式及图表缓存失效后请求 Excel 重算。后续结果批次先保留已有数据及来源，再明确本次是完整快照还是增量，不能默默丢弃已登记结果。
- 用户确认对应 anchor 和可比范围后，分别计算 Y/U/V 的 BD-rate，再按 `(6×Y+U+V)/8` 加权。序列等权均值与类别等权均值分别列出，不把不同配置混为一个总体数值。
- 整体 BD-rate 仅使用四个 QP 齐全的实验曲线。逐 QP BD-rate 每次仅替换完整 anchor 曲线中目标 QP 的完整 RD 元组，其余 QP 仍用 anchor；缺失点不填零，不借其他实验点补齐。

### 模板与计算口径

Reference 和 Test 均无表头，A 列为任务键；B:K 依次为 kbps、Y/U/V PSNR、编码秒、解码秒、编码峰值 KB、解码峰值 KB、状态和时间。50 个实测点均可唯一定位到 Test。

原模板存在历史内容：Summary 的旧软件标签、LP 的重复 DaylightRoad2 QP37 行及缺失 ParkRunning3 QP37 行，以及部分逐 QP 页的非目标点仍引用 Test。它们不影响本批 50 点的匹配；原件和这些公式未擅自改写。本批 BD-rate 由已核对算法独立复算，不引用模板旧缓存或有问题的逐 QP 公式。

采用原模板 VBA `bdrate` 的四点 PCHIP 算法：以 PSNR 为横轴、`log10(kbps)` 为纵轴，在两条曲线的 PSNR 交集上积分；`100 × (10^((I_test−I_anchor)/(上界−下界))−1)` 得到百分数。先检查四点完整、有限正码率、严格单调和非空交集，不外推；不使用 `bdrateOld` 的全局三次拟合。6:1:1 对应原表 AC 列计算口径，AB 列不是该权重。

逐 QP 表按本文件登记约定复算，每个分量使用其各自的 PSNR 交集。逐 QP 数值不能相加还原整体 BD-rate。表中 `—` 表示本批缺失或无法计算；不得当作零。
